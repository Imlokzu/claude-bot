# Проєкт «Клод Бот»

«Клод Бот» — саморобний AI-компаньйон. Ціль: фізичний робот на Raspberry Pi 3,
що спілкується українською, бачить камерою, показує емоції на маленькому дисплеї
та памʼятає розмови. «Мозок» — Claude API (через OpenClaw gateway або напряму),
важкі обчислення — на домашньому сервері (i5).

## Складові проєкту

- **Voice Loop** — цикл голосового спілкування: STT (faster-whisper) → мозок → TTS.
- **Vision Agent** — FastAPI-сервіс зору (порт 8000): детекція облич і руху,
  снапшоти та MJPEG-стрім з вебки.
- **claude-bot-display** — віртуальний TFT-дисплей 320x240 (порт 8001):
  піксельні очі з емоціями, екрани статусу/розмови.
- **Virtual Bot** — віртуальне втілення бота + веб-панель керування (порт 8100):
  чат з емоціями, зір, памʼять, керування сервісами. Це я!

## Режими мозку (за пріоритетом)

1. OpenClaw gateway (127.0.0.1:18789);
2. прямий Anthropic API (claude-sonnet-5);
3. демо-режим із заготовленими відповідями — щоб я працював завжди.
